# Outreach plan and prepared messages

**Do not post until the repository URL is live, its initial content is audited and its status/contacts are readable.** No social post, Discord message or external issue was sent during this preparation.

## First audience

Start with maintainers/contributors working on relevant ps3recomp components and the same-title project. Review each community's posting rules before a single focused introduction. Avoid mass tagging, repeated promotional messages, claims of partnership or presenting existing upstream achievements as ours. The first request should offer a minimal reproducible host problem, not demand a complete free port.

Broader game communities come next. A short visual update should only use evidence from the actual build and must distinguish native rendering, decoded videos and emulator/reference captures. Do not market component PASS counts as menu completion.

## English announcement draft

I'm Franklin Wilster (FrankCG), from Brazil, and I initiated an independent **Twisted Metal (2012, PS3) native-PC-port research effort**. Development uses ChatGPT and Codex extensively, with evidence-based testing and review. This is **not a playable release** and not a claim of first-ever porting work on the title.

We're opening focused contributions around SPURS/Taskset representation, context lifetime, memory coherence and Windows host integration, plus independent tooling, graphics, audio and input contracts. The initial source export includes a synthetic no-game test and historical host-model reference sources; the full runtime export is still a tracked task.

No game/firmware assets, keys or private dumps are distributed. Contributions and upstream authorship will be credited. Please start with one scoped issue/PR rather than a large runtime rewrite.

Repository: https://github.com/franklincg/twisted-metal-2012-ps3-native-port
